## 工程与运维

该站点采用静态化发布方式，并持续进行页面与内容迭代。部署与维护过程中包含：

- Nginx 静态站点配置与路由处理
- Cloudflare 域名接入与 HTTPS 访问
- 版本化 release 发布与符号链接原子切换
- 上线前本地 HTTP smoke test
- 上线后公网状态码与关键页面验证
- 保留上一版本以支持快速回滚
- 静态资源、旧备份文件和历史链接清理

## 当前维护方向
